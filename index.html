Sobre o projeto

Este projeto foi desenvolvido como prática de programação com Python e ferramentas de inteligência artificial. A proposta é construir um mentor de carreira que responda a perguntas e ajude o usuário a refletir sobre suas metas, competências e opções de desenvolvimento.

PythonGoogle ColabAPIOpenRouterEngenharia de Prompt

O que estou estudando

  1. Preparar o ambiente no Google Colab.
  2. Conectar a aplicação a um modelo de IA via API.
  3. Usar Secrets para proteger credenciais.
  4. Construir e ajustar System Prompt e GuardRails.
  5. Entender tokens e consumo da API.
  6. Testar respostas e aprimorar o mentor.
