# Radar Carreira — Descubra caminhos que combinam com você

Aplicação interativa em português que ajuda usuários a explorar possibilidades de carreira por meio de perguntas sobre interesses, estilo de trabalho, motivadores e preferências.

## Como usar
1. Abra `index.html` em um navegador, ou publique-o pelo GitHub Pages.
2. Clique em **Começar descoberta** e responda às 7 perguntas.
3. Veja seu perfil principal e complementar, carreiras sugeridas e plano inicial de exploração.

## Publicar no GitHub Pages
- Coloque `index.html` na raiz do repositório.
- GitHub → Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save.
- Aguarde a publicação. A página é estática e funciona sem backend.

## Nota
O matching é uma heurística simples de interesses, não usa API/LLM nem substitui aconselhamento profissional. Nenhuma resposta é enviada ou armazenada em servidor.
